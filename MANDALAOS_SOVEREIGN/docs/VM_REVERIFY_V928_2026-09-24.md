## Limits and discoveries

- This validates a VM boot and in-guest containment on the v9.2.8 source pin.
  It does not prove an unassisted installation, physical hardware behavior,
  or a hostile-tenant microVM boundary. Containment remains shared-kernel.
- Guest `wm doctor` reports the Yama collector feed absent and at-rest mode
  `off`; both are informational for this VM configuration and should remain
  visible in future-project planning.
- The public WhiteMagic `v9.2.8` tag's Rust `wm-receipts` dependency is
  `continuity-receipt 0.3.1`. Gate-lite's separate Python 0.4 exercise is
  therefore not a cross-component receipt compatibility test.
